# 分布式 Checkpoint 与恢复

**阶段：** 分布式训练  
**建议时间：** 第 20 周后半段  
**前置条件：** 完成任务 37-38

## 目标

保存模型、优化器、学习率、随机状态和训练进度，并在进程故障后正确恢复。

## 实现说明

- checkpoint schema 包含模型、优化器、调度器、scaler、epoch/step、随机状态、数据游标和配置摘要。
- 写入采用临时文件加原子替换，元数据中保存 schema 版本和完整性信息。
- `recover.sh` 先运行到指定 step 并终止，再从最新完整 checkpoint 启动相同命令。

## 学习与复现

1. 定义完整 checkpoint schema 和版本信息。
2. 定期保存到所有 Worker 可访问的持久存储。
3. 在固定 step 主动终止一个训练进程。
4. 重启训练并从最近 checkpoint 恢复。
5. 对比连续训练与恢复训练的 loss 和参数。
6. 分别运行“不中断基线”和“中断后恢复”，比较相同步数的模型摘要。
7. 扩展实验：截断 checkpoint 文件，验证加载逻辑明确拒绝损坏数据。

## 验收标准

- 恢复后不会从错误 step 重复或跳过数据。
- 模型和优化器状态完整恢复。
- 损坏或不兼容 checkpoint 会明确失败。

## 产出

- Checkpoint 工具与恢复脚本。
- 故障时间线和一致性验证报告。
