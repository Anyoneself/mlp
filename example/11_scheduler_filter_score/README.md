# Scheduler Filter 与 Score

**阶段：** Kubernetes 调度器  
**建议时间：** 第 6 周后半段  
**前置条件：** 完成任务 10，具备基础 Go 能力

## 目标

实现最小 Filter 和 Score 插件逻辑，理解可行性过滤与节点排序的边界。

## 实现说明

- Go 包按插件入口、配置、Filter、Score 和测试拆分，插件不直接依赖真实集群状态以便单测。
- Filter 只判断节点是否可行并返回明确原因，Score 只对通过 Filter 的节点排序。
- 使用表驱动测试覆盖缺失标签、边界资源、同分节点和归一化结果。

## 学习与复现

1. 定义 Pod 所需标签和节点评分规则。
2. 实现 Filter，返回不可调度原因。
3. 实现 Score，为候选节点生成原始分数。
4. 实现或验证 NormalizeScore。
5. 编写无候选节点、单节点和多节点单元测试。
6. 扩展实验：改变评分权重，验证最终节点选择如何变化。

## 验收标准

- Filter 原因可读且能对应具体约束。
- Score 在合法范围内，排序结果可预测。
- 测试覆盖边界值和缺失标签。

## 产出

- Go 插件原型。
- 表驱动单元测试。
