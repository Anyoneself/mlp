# 小模型 GRPO/PPO

**阶段：** veRL/RLHF  
**建议时间：** 第 22 周后半段  
**前置条件：** 完成任务 41-42

## 目标

跑通一个小模型 GRPO 或 PPO 训练，并验证奖励、loss 与 checkpoint。

## 实现说明

- 训练配置固定模型、数据、奖励函数、随机种子、batch 和生成参数，并纳入版本控制。
- `smoke_test.sh` 使用极小步数检查数据、Rollout、Reward、反向传播和 checkpoint 全链路。
- `report.py` 从训练日志生成 reward、KL、loss、长度、吞吐和 GPU 利用率曲线。

## 学习与复现

1. 固定小模型、数据集和奖励函数。
2. 先用极小 batch 完成端到端 dry run。
3. 运行短训练并记录生成、奖励和更新指标。
4. 保存 checkpoint 并验证恢复。
5. 调整一个关键参数并比较训练稳定性。
6. 先完成 smoke test，再延长训练；每次只修改一个参数并使用独立输出目录。
7. 扩展实验：在资源允许时用同一数据比较 GRPO 和 PPO 的吞吐与显存。

## 验收标准

- 训练能够完成多个更新 step。
- 奖励和 loss 无持续 NaN 或明显失控。
- 能解释主要耗时和显存分布。

## 产出

- 可复现训练配置。
- 指标、checkpoint 和实验结论。
