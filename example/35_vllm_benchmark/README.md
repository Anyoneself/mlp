# vLLM 综合压测

**阶段：** vLLM  
**建议时间：** 第 18 周  
**前置条件：** 完成任务 31-34

## 目标

使用统一负载对比单卡、单机多卡和 Ray 多节点三种架构。

## 执行步骤

1. 固定模型、数据集、输入输出长度和质量参数。
2. 设计并发阶梯和持续稳定负载。
3. 对三种部署分别采集吞吐、TTFT、TPOT、P95/P99 和错误率。
4. 采集 GPU 利用率、显存、KV Cache 和功耗或成本。
5. 找出每种架构的饱和点和适用区间。

## 验收标准

- 三组实验使用相同统计口径。
- 原始数据、配置和图表可以复现。
- 结论同时考虑性能、稳定性和部署复杂度。

## 产出

- 自动化压测脚本。
- 三种部署模式的性能与成本报告。
