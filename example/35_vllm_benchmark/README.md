# vLLM 综合压测

**阶段：** vLLM  
**建议时间：** 第 18 周  
**前置条件：** 完成任务 31-34

## 目标

使用统一负载对比单卡、单机多卡和 Ray 多节点三种架构。

## 实现说明

- `workload.json` 固定模型、请求数量、输入输出长度分布和并发阶梯。
- `benchmark.py` 对不同 endpoint 使用同一请求生成与统计逻辑，原始数据不覆盖。
- `report.py` 从原始记录生成吞吐、TTFT、TPOT、P95/P99、错误率和成本图表。

## 学习与复现

1. 固定模型、数据集、输入输出长度和质量参数。
2. 设计并发阶梯和持续稳定负载。
3. 对三种部署分别采集吞吐、TTFT、TPOT、P95/P99 和错误率。
4. 采集 GPU 利用率、显存、KV Cache 和功耗或成本。
5. 找出每种架构的饱和点和适用区间。
6. 每种部署至少运行一次预热和三次正式实验，报告中展示离散程度。
7. 扩展实验：增加一种长上下文负载，判断架构排序是否改变。

## 验收标准

- 三组实验使用相同统计口径。
- 原始数据、配置和图表可以复现。
- 结论同时考虑性能、稳定性和部署复杂度。

## 产出

- 自动化压测脚本。
- 三种部署模式的性能与成本报告。
