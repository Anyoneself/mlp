# Go Scheduler Plugin

**阶段：** Kubernetes 调度器  
**建议时间：** 第 8 周  
**前置条件：** 完成任务 10-13

## 目标

完成一个可部署、可配置、可测试的 GPU 节点调度插件。

## 执行步骤

1. 定义 GPU 容量、利用率和碎片评分输入。
2. 实现 Filter 与 Score，并提供清晰状态信息。
3. 接入 Scheduler Profile 和插件配置。
4. 增加结构化日志与 Prometheus 指标。
5. 构建镜像，在测试集群运行集成实验。

## 验收标准

- GPU 不足节点被正确过滤。
- 节点评分与测试数据一致。
- 配置错误和指标采集不会使调度器崩溃。
- 单元测试与最小集成测试通过。

## 产出

- Go Scheduler Plugin 源码。
- 镜像、部署清单、测试和使用文档。
