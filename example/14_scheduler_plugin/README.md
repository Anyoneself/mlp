# Go Scheduler Plugin

**阶段：** Kubernetes 调度器  
**建议时间：** 第 8 周  
**前置条件：** 完成任务 10-13

## 目标

完成一个可部署、可配置、可测试的 GPU 节点调度插件。

## 实现说明

- 插件分为配置解析、节点指标快照、Filter、Score、指标暴露和注册入口。
- 调度周期使用一致的指标快照，避免 Filter 与 Score 读取不同时间点造成结果漂移。
- 单元测试使用假 NodeInfo 和 Pod；集成测试使用独立 schedulerName，避免影响默认调度器。

## 学习与复现

1. 定义 GPU 容量、利用率和碎片评分输入。
2. 实现 Filter 与 Score，并提供清晰状态信息。
3. 接入 Scheduler Profile 和插件配置。
4. 增加结构化日志与 Prometheus 指标。
5. 构建镜像，在测试集群运行集成实验。
6. 扩展实验：让指标源超时，验证插件采用明确的失败或降级策略。

## 验收标准

- GPU 不足节点被正确过滤。
- 节点评分与测试数据一致。
- 配置错误和指标采集不会使调度器崩溃。
- 单元测试与最小集成测试通过。
