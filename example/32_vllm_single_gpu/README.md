# vLLM 单卡部署

**阶段：** vLLM  
**建议时间：** 第 16 周后半段  
**前置条件：** 完成任务 31

## 目标

建立单 Pod、单 GPU 的部署和性能基线。

## 执行步骤

1. 计算模型权重、运行时和 KV Cache 的显存需求。
2. 使用 `TP=1`、`PP=1` 启动模型。
3. 设置明确的上下文长度、并发和显存利用率参数。
4. 运行固定输入输出长度的阶梯并发压测。
5. 记录吞吐、延迟、显存、错误和 OOM。

## 验收标准

- 服务稳定运行且不会持续 OOM。
- 压测参数、模型版本和硬件信息完整记录。
- 得到后续多卡与 Ray 实验可比较的基线。

## 产出

- 单卡启动和部署配置。
- 单卡性能基线报告。
