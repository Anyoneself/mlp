# vLLM 单卡部署

**阶段：** vLLM  
**建议时间：** 第 16 周后半段  
**前置条件：** 完成任务 31

## 目标

建立单 Pod、单 GPU 的部署和性能基线。

## 实现说明

- `deployment.yaml` 固定单 GPU requests/limits、模型缓存卷、探针和安全配置。
- `start_server.sh` 显式设置 `TP=1`、`PP=1` 及所有影响容量的 vLLM 参数。
- `benchmark.py` 使用固定随机种子生成负载，输出原始请求记录和聚合分位数。

## 学习与复现

1. 计算模型权重、运行时和 KV Cache 的显存需求。
2. 使用 `TP=1`、`PP=1` 启动模型。
3. 设置明确的上下文长度、并发和显存利用率参数。
4. 运行固定输入输出长度的阶梯并发压测。
5. 记录吞吐、延迟、显存、错误和 OOM。
6. 从并发 1 开始逐级压测，找到错误率或 P99 明显恶化前的稳定容量。
7. 扩展实验：只调整 `gpu-memory-utilization`，比较并发容量与 OOM 风险。

## 验收标准

- 服务稳定运行且不会持续 OOM。
- 压测参数、模型版本和硬件信息完整记录。
- 得到后续多卡与 Ray 实验可比较的基线。

## 产出

- 单卡启动和部署配置。
- 单卡性能基线报告。
