# Gang Scheduling 与资源碎片

**阶段：** 调度算法  
**建议时间：** 第 10 周  
**前置条件：** 完成任务 15-16

## 目标

模拟多 Worker 作业的原子调度、回填和 GPU 碎片问题。

## 执行步骤

1. 为 Job 增加最小成员数和多维资源需求。
2. 实现全员满足才启动的 Gang Scheduling。
3. 增加小任务 backfilling 策略。
4. 设计不同 GPU 型号和显存需求，计算碎片率。
5. 比较 FIFO、Gang 和 Gang+Backfilling。

## 验收标准

- 不会出现只启动部分 Worker 的死锁状态。
- 指标包含排队时间、成功率、抢占次数和碎片率。
- 能解释回填何时改善利用率、何时拖慢大作业。

## 产出

- 完整调度模拟器。
- 三种策略的实验数据和图表。
