# vLLM 单机多卡部署

**阶段：** vLLM  
**建议时间：** 第 17 周前半段  
**前置条件：** 完成任务 32，具备多张 GPU

## 目标

使用 Tensor Parallel 或 Pipeline Parallel 部署单机多卡模型，并分析通信开销。

## 执行步骤

1. 选择适合 GPU 数量和模型结构的 TP/PP 组合。
2. 启动单机多卡服务并验证各卡显存占用。
3. 使用与单卡一致的负载压测。
4. 观察 GPU 利用率、通信和负载均衡。
5. 对比扩卡后的吞吐、延迟与单位请求成本。

## 验收标准

- 模型正确切分到预期 GPU。
- 能解释吞吐未线性增长的主要瓶颈。
- 对比口径与单卡基线一致。

## 产出

- 多卡启动配置。
- 单卡与多卡对比报告。
