# vLLM 单机多卡部署

**阶段：** vLLM  
**建议时间：** 第 17 周前半段  
**前置条件：** 完成任务 32，具备多张 GPU

## 目标

使用 Tensor Parallel 或 Pipeline Parallel 部署单机多卡模型，并分析通信开销。

## 实现说明

- 部署配置一次性请求所需 GPU 数，避免模型 Worker 被拆到不同 Pod。
- 启动脚本将 TP、PP、模型版本和通信相关环境变量全部参数化并写入日志。
- 压测复用任务 32 的数据集和统计代码，只改变并行配置。

## 学习与复现

1. 选择适合 GPU 数量和模型结构的 TP/PP 组合。
2. 启动单机多卡服务并验证各卡显存占用。
3. 使用与单卡一致的负载压测。
4. 观察 GPU 利用率、通信和负载均衡。
5. 对比扩卡后的吞吐、延迟与单位请求成本。
6. 先验证每张卡的模型分片和显存，再运行与单卡完全相同的并发阶梯。
7. 扩展实验：在 GPU 数允许时比较两组 TP/PP 组合，并记录通信开销。

## 验收标准

- 模型正确切分到预期 GPU。
- 能解释吞吐未线性增长的主要瓶颈。
- 对比口径与单卡基线一致。

## 产出

- 多卡启动配置。
- 单卡与多卡对比报告。
