# Python 异步任务队列

**阶段：** 基础补齐  
**建议时间：** 第 2 周后半段  
**前置条件：** Python 3.10+

## 目标

使用 `asyncio` 实现带并发限制、超时、重试和优雅退出的异步任务队列。

## 实现说明

- 使用 `asyncio.Queue` 保存待处理任务，由固定数量消费者控制并发。
- 用 `asyncio.timeout()` 或 `wait_for()` 限制单任务时间，只对可恢复错误进行有限重试。
- 主协程等待 `queue.join()`，再发送停止信号并回收消费者，确保没有悬挂任务。

## 学习与复现

1. 使用 `asyncio.Queue` 连接生产者与消费者。
2. 创建固定数量消费者限制并发。
3. 为任务增加超时和有限次数重试。
4. 注入成功、超时与永久失败任务。
5. 使用 sentinel 或取消机制实现优雅退出。
6. 扩展实验：调整队列容量和消费者数量，观察背压与总耗时。

## 验收标准

- 所有任务都进入成功或失败终态。
- 超时任务不会无限占用 Worker。
- 退出后没有悬挂协程或未处理异常。
