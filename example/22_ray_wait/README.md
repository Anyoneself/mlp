# Wait For Tasks

## 学习目标

使用 `ray.wait()` 分批获取已完成任务，避免等待全部任务结束后才开始处理结果。

## 核心 API

- `ray.wait()`：将引用分为已就绪和未就绪两组。
- `num_returns`：指定每次等待的结果数量。
- `ray.get()`：读取本轮已就绪结果。

## 执行流程

1. 提交 3 个具有不同延迟的任务。
2. 每次等待 1 个任务完成。
3. 立即处理已完成结果，并继续等待剩余任务。
4. 验证所有结果均被处理。

## 运行

```bash
python example/22_ray_wait/main.py
```

输出包含 1、2、3，例如：

```text
[2, 3, 1]
```

## 注意事项

分布式任务的实际完成顺序不应作为业务正确性的前提，因此代码只验证结果集合，不验证固定顺序。
