# Bin Packing 与 Spread

**阶段：** 调度算法  
**建议时间：** 第 9 周前半段  
**前置条件：** 完成 Kubernetes 调度器阶段

## 目标

用同一批工作负载比较紧凑装箱与负载分散策略。

## 实现说明

- 用不可变输入模型描述 Node 和 Task，调度结果单独保存，便于多个算法复用同一工作负载。
- Bin Packing 按放置后剩余资源最少排序，Spread 按剩余资源最多或利用率最低排序。
- 指标模块统一计算利用率、空闲节点、失败任务和多维资源碎片。

## 学习与复现

1. 定义节点 CPU、内存和任务需求数据模型。
2. 实现 First Fit 或 Best Fit Bin Packing。
3. 实现按剩余容量优先的 Spread。
4. 对相同输入运行两种策略。
5. 统计利用率、空闲节点数、失败任务和资源碎片。
6. 扩展实验：改变任务到达顺序，观察贪心算法结果是否稳定。

## 验收标准

- 两种算法使用同一输入和指标口径。
- 能解释高利用率与故障隔离、热点风险的取舍。
- 结果可通过固定随机种子复现。

## 产出

- 调度模拟代码。
- 策略对比表和结论。
