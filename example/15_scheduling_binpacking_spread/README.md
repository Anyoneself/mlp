# Bin Packing 与 Spread

**阶段：** 调度算法  
**建议时间：** 第 9 周前半段  
**前置条件：** 完成 Kubernetes 调度器阶段

## 目标

用同一批工作负载比较紧凑装箱与负载分散策略。

## 执行步骤

1. 定义节点 CPU、内存和任务需求数据模型。
2. 实现 First Fit 或 Best Fit Bin Packing。
3. 实现按剩余容量优先的 Spread。
4. 对相同输入运行两种策略。
5. 统计利用率、空闲节点数、失败任务和资源碎片。

## 验收标准

- 两种算法使用同一输入和指标口径。
- 能解释高利用率与故障隔离、热点风险的取舍。
- 结果可通过固定随机种子复现。

## 产出

- 调度模拟代码。
- 策略对比表和结论。
