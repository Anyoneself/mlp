# 综合项目扩缩容、抢占与混部

**阶段：** 综合项目  
**建议时间：** 第 23 周中段  
**前置条件：** 完成任务 44

## 目标

设计在线与离线任务共享 CPU/GPU 集群时的优先级、借用、回收和扩缩容策略。

## 实现说明

- `policy.yaml` 描述队列优先级、保底配额、可借用上限、抢占顺序和排空期限。
- `simulation.py` 输入流量和任务到达序列，输出容量、排队、抢占、饥饿和成本指标。
- 集群配置将 Kubernetes Priority 与 Ray 应用层队列分开设计，避免混淆两层抢占。

## 学习与复现

1. 定义在线、离线和紧急任务的优先级与 SLO。
2. 设置保底配额、可借用容量和最大占用。
3. 设计抢占顺序、排空期限和恢复方式。
4. 选择扩缩容指标与冷却窗口。
5. 用模拟流量验证突发、回落和容量不足。
6. 先用模拟器验证策略，再在隔离测试环境应用配置并逐步增加负载。
7. 扩展实验：缩短扩容冷却时间，观察震荡和成本变化。

## 验收标准

- 在线 SLO 与离线吞吐都有明确保护边界。
- 不会因循环扩缩或反复抢占造成震荡。
- 饥饿、成本和恢复时间有量化指标。

## 产出

- 调度与扩缩容策略。
- 场景测试和参数选择报告。
