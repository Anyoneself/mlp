# 综合项目扩缩容、抢占与混部

**阶段：** 综合项目  
**建议时间：** 第 23 周中段  
**前置条件：** 完成任务 44

## 目标

设计在线与离线任务共享 CPU/GPU 集群时的优先级、借用、回收和扩缩容策略。

## 执行步骤

1. 定义在线、离线和紧急任务的优先级与 SLO。
2. 设置保底配额、可借用容量和最大占用。
3. 设计抢占顺序、排空期限和恢复方式。
4. 选择扩缩容指标与冷却窗口。
5. 用模拟流量验证突发、回落和容量不足。

## 验收标准

- 在线 SLO 与离线吞吐都有明确保护边界。
- 不会因循环扩缩或反复抢占造成震荡。
- 饥饿、成本和恢复时间有量化指标。

## 产出

- 调度与扩缩容策略。
- 场景测试和参数选择报告。
