# Linux 进程与网络排障

**阶段：** 基础补齐  
**建议时间：** 第 1 周前半段  
**前置条件：** Linux 主机或 Linux 容器

## 目标

掌握从进程、文件描述符、端口和系统负载四个方向定位服务异常。

## 执行步骤

1. 启动一个持续占用 CPU 的进程和一个监听本地端口的 HTTP 服务。
2. 使用 `ps`、`top`、`pidstat` 查看进程和线程状态。
3. 使用 `lsof`、`ss` 查看文件描述符与监听端口。
4. 使用 `vmstat`、`free`、`df` 记录 CPU、内存和磁盘状态。
5. 终止服务并观察退出码、信号和端口释放情况。

## 验收标准

- 能从端口反查进程，也能从 PID 找到监听端口。
- 能区分 CPU 饱和、内存不足、磁盘不足和端口冲突。
- 能整理一份包含命令、现象和判断依据的排障记录。

## 产出

- `diagnostics.md`：命令输出摘要与故障判断。
- 可重复启动的测试服务脚本。
