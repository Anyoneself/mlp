# DRF 与公平性

**阶段：** 调度算法  
**建议时间：** 第 9 周后半段  
**前置条件：** 完成任务 15

## 目标

实现 Dominant Resource Fairness，分析多租户 CPU、内存和 GPU 份额。

## 实现说明

- 资源向量统一归一化为集群总容量占比，租户的最大维度占比即 dominant share。
- 调度循环从 dominant share 最小且当前请求可放置的租户中选择任务。
- 权重、配额和不可调度请求作为独立策略层，不写死在份额计算中。

## 学习与复现

1. 定义多维集群容量和租户资源需求。
2. 计算每个租户的 dominant share。
3. 每轮为 dominant share 最小的可调度租户分配任务。
4. 加入权重、配额和无法满足的资源请求。
5. 与 FIFO 策略比较等待时间和资源份额。
6. 扩展实验：增加 GPU 稀缺租户，观察 dominant resource 如何变化。

## 验收标准

- dominant share 计算正确。
- 不同资源主导的租户都能获得可解释的公平份额。
- 能说明公平、利用率和优先级之间的冲突。

## 产出

- DRF 模拟器。
- 多租户公平性分析报告。
