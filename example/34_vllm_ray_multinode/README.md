# vLLM Ray 多节点部署

**阶段：** vLLM  
**建议时间：** 第 17 周后半段  
**前置条件：** 完成任务 30、33，具备多节点 GPU 集群

## 目标

使用 Ray Distributed Executor 将 vLLM 部署到多个 GPU 节点。

## 执行步骤

1. 确认每个 Ray Worker 的 GPU 与网络资源注册正确。
2. 使用 Placement Group 验证所需资源可同时满足。
3. 配置 TP/PP 并启动跨节点服务。
4. 记录跨节点通信、启动时间和推理指标。
5. 删除一个 Worker，观察服务失败与恢复边界。

## 验收标准

- Worker 拓扑和模型并行拓扑可对应。
- 能解释何时需要 Ray，何时直接单 Pod 更简单。
- 跨节点性能损耗和故障表现有量化数据。

## 产出

- Ray 多节点部署配置。
- 拓扑、性能和故障实验报告。
