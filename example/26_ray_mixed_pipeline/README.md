# Ray CPU/GPU 混合流水线

**阶段：** Ray Core  
**建议时间：** 第 13 周  
**前置条件：** 完成任务 18-25；无 GPU 时使用自定义资源模拟

## 目标

组合 Task、Actor、Object Store、资源声明和 Placement Group，构建完整处理流水线。

## 执行步骤

1. 实现数据读取和 CPU 预处理 Task。
2. 实现长期存活的模型 Actor，并声明 GPU 或模拟资源。
3. 实现 CPU 后处理 Task。
4. 使用 ObjectRef 串联各阶段，使用 Placement Group 控制资源位置。
5. 注入任务失败并记录重试、排队和执行时间。

## 验收标准

- 每个阶段资源声明明确，流水线结果正确。
- 多个请求能够并发执行，模型 Actor 可以复用。
- 故障恢复行为和幂等边界有记录。

## 产出

- 可运行的混合流水线。
- 阶段耗时、资源拓扑和故障实验报告。
